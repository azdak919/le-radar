iFrames

Deux cadres HTML pour coller LE-RADAR.ca sur un site de campus : la barre radio, et la colonne de cartes sports. Aucun compte, aucun script obligatoire.

Barre radio

Le même synthétiseur que sur le site. Coller le bloc dans n’importe quelle page HTML. Hauteur fixe 62 px.

Aperçu

<iframe
  src="https://le-radar.ca/tuner-embed.html"
  title="Radios étudiantes — LE-RADAR.ca"
  loading="lazy"
  referrerpolicy="strict-origin-when-cross-origin"
  allow="autoplay; encrypted-media"
  style="width:100%;height:62px;border:0;overflow:hidden;"
></iframe>

Pour coller le look de la barre bureau, ajoutez ?surface=kiosque-v1 à l’URL et passez la hauteur à 68px.

Cartes sports

La carte CTA du mât, en colonne. Tous les quelques résultats, une carte LE-RADAR.ca s’intercale : un clic ouvre le-radar.ca (nouvel onglet). Largeur conseillée 390 px.

Aperçu

<iframe
  src="https://le-radar.ca/sports-embed.html"
  title="Sports étudiants — LE-RADAR.ca"
  loading="lazy"
  referrerpolicy="strict-origin-when-cross-origin"
  style="width:100%;max-width:390px;height:520px;border:0;overflow:hidden;"
></iframe>
ParamètreDéfautEffet
every 4 Carte marque LE-RADAR.ca après autant de résultats (2 à 8).
n 8 Nombre total de cartes, promo comprise (1 à 16).

Exemple : sports-embed.html?every=3&n=10 — une carte marque tous les 3 résultats, 10 cartes au plus.

Hauteur automatique (optionnel)

Si vous voulez que la colonne sports suive le nombre de cartes, écoutez le message envoyé par l’iframe. Le script ci-dessous est facultatif : une hauteur fixe de 520 px suffit dans la plupart des cas.

<iframe
  id="radar-sports"
  src="https://le-radar.ca/sports-embed.html"
  title="Sports étudiants — LE-RADAR.ca"
  loading="lazy"
  referrerpolicy="strict-origin-when-cross-origin"
  style="width:100%;max-width:390px;height:520px;border:0;overflow:hidden;"
></iframe>
<script>
window.addEventListener("message", function (e) {
  if (e.origin !== "https://le-radar.ca") return;
  if (e.data && e.data.type === "radar-sports-embed" && e.data.height) {
    document.getElementById("radar-sports").style.height = e.data.height + "px";
  }
});
</script>
