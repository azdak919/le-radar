# Logos d'équipes (story « Jour de match »)

Déposer ici, **à la main**, le logo d'une équipe : `<registryId>.svg` (préféré), `.png` ou `.webp`.
`registryId` = identifiant de l'établissement dans `sports-masthead.json` (`registryId` / `opponentRegistryId`),
ex. `mcgill.svg`, `concordia.png`, `montmorency.svg`.

- Utilisé seulement par l'affiche story 9:16 `scripts/social/match-story-run.mjs` (format `match-story`).
- Sans fichier : l'affiche reste typographique (nom + couleur de l'établissement). Rien n'est téléchargé automatiquement.
- Marques de commerce des établissements : ajouter un logo seulement avec une autorisation ou une source qui le permet ;
  noter la provenance dans `THIRD_PARTY.md`. Fond transparent, ≥ 400 px de côté.
