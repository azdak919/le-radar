# Fontes du générateur d’affiches

**Caveat Bold** — The Caveat Project Authors, licence SIL OFL 1.1 (`CAVEAT-OFL.txt`).
Signature manuscrite des messages de rentrée / session / fêtes.

**Noto Sans Regular** — The Noto Project Authors, licence SIL OFL 1.1 (`langs/OFL.txt`).
Endonymes du pied d’affiche (toutes les écritures de `TRANSLATE_LANGS`), graisse 400 uniquement.
Fichiers sous-ensemble : `langs/*.woff2`. Pour régénérer : `python3 scripts/subset-poster-lang-fonts.py`.

**Noto Sans Symbols** — The Noto Project Authors, licence SIL OFL 1.1 (`langs/OFL.txt`).
Sous-ensemble d’un seul glyphe, U+1F12F (copyleft), servi comme `LR Copyleft` dans le pied des affiches (`noto-sans-symbols-copyleft.woff2`), graisse 400, pour accompagner Inter / LR Sans.
